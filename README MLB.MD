# Análisis de Eficiencia MLB: ¿Billetera mata Galán? ⚾📊

Este proyecto analiza 20 años de datos de la MLB para determinar la relación entre el gasto (Payroll) y el éxito deportivo (Win Percentage).

## ¿Qué vas a encontrar aquí?

- **Limpieza de datos:** Un pipeline completo para cruzar nóminas salariales y estadísticas de victorias.
- **Validación Estadística:** Implementación de modelos de regresión con `Scikit-Learn` para medir el impacto real del dinero.
- **Visualización de Datos:** Gráficos interactivos con `Plotly` para identificar equipos "eficientes" (outliers).

## Hallazgos Principales

- El **$R^2$ de 0.32** sugiere que el dinero no es el único factor determinante.
- 
- Los equipos "outliers" (con alta eficiencia) son los que realmente demuestran innovación estratégica.
